# Release v1.0.0 — 2026-11-17

## Summary

First public release of the **MT5 AI Performance** dashboard: a live, read-only web view of the HERMES autonomous MT5 trading bot's equity, risk, positions, trades, AI lessons and decision journal, published from a single personal Exness USC Cent account.

**Version type:** major (initial public release)

## What changed

### Added

- **Live dashboard** (`index.html`) reading `data.json` in the browser:
  - capital horizon: balance, equity, peak equity, floor cushion and progress to the `8,000 USC` target;
  - risk guardrails: daily P&L against the `-8.00%` limit, open risk vs ceiling, position and pending-order caps;
  - cumulative P&L / equity / drawdown chart with `AI ERA`, `7D` and `ALL` ranges;
  - core metrics: net P&L, win rate, profit factor, average R, max drawdown and exit mix;
  - symbol matrix, open positions, pending orders, closed-trade ledger, AI lessons and decision journal;
  - automatic refresh every 60 seconds, plus a manual refresh button.
- **GitHub Pages deployment** at <https://plub-supanut.github.io/mt5-ai-performance/>.
- **Data contract:** `data.json` (auto-generated snapshot) and `schema.sql` (SQLite history schema used by the bot).
- **Repository standard scaffolding:** README blueprint rewrite, banner + dashboard screenshot + 1280×640 social preview in `assets/`, `CHANGELOG.md`, release notes, `.gitattributes`, `.editorconfig`, explicit `LICENSE` and issue/PR templates.
- **CI** on every push to `main` and every pull request: validates `data.json` structure, static assets and obvious secret patterns.

### Changed

- Data provenance is now stated explicitly: one personal **Exness USC (Cent)** account, exported automatically roughly every 15 minutes by a private sync pipeline; not audited and not representative of other accounts.

### Security

- No account numbers, login, server name, investor password or broker credentials are published.
- CI scans tracked files for obvious secret patterns on every push and pull request.

## Who it affects

- **Dashboard visitors:** new public dashboard; no account or login is needed. Read-only.
- **The operator / sync pipeline:** nothing to change — `data.json` keeps the same shape (`generated_at`, `account`, `stats_all`, `equity_snapshots`, `trades`, plus optional sections).
- **Anyone consuming `data.json`:** first public, stable shape. Treat values as a periodic snapshot of one personal account.

## How to use / upgrade

1. Open the live dashboard: <https://plub-supanut.github.io/mt5-ai-performance/>
2. Or download `mt5-ai-performance-v1.0.0.zip` from the release assets, unzip it, and serve the folder:
   ```bash
   cd mt5-ai-performance-v1.0.0
   python -m http.server 8080
   ```
3. Open <http://localhost:8080>. There is no installation, build step, login or API key.
4. Opening `index.html` directly via `file://` will not work — the page must be served over HTTP so it can fetch `data.json`.

No migration is required: this is the first public release.

## Known issues

- **Snapshot lag:** `data.json` is rebuilt roughly every 15 minutes, so open positions and floating P&L can lag live MT5 by up to one sync interval. The dashboard refreshes every 60 seconds but only sees the latest committed snapshot.
- **Single account, personal scale:** all metrics come from one small personal cent account and are not audited. Do not generalise them to other accounts or strategies.
- **Thai-first UI:** labels and notes are primarily Thai; metric names are English. Not fully localised yet.
- **GitHub Pages dependency:** if Pages is unavailable, the live URL is unavailable; the release zip remains usable locally.
- **History depth:** the dashboard only shows history present in the current `data.json` snapshot; older records depend on the bot's private database retention.
- **Mobile:** the layout is responsive but dense tables (ledger, journal) are best viewed on a wide screen.
